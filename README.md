# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

菜单另有「钟点闸」专页：每日禁写闭区间配置、此刻是否禁写（按服务器时间判定）、禁写痕迹。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3195 |
| 接口 | http://localhost:8195 |
| PostgreSQL | localhost:54395 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| calibrator | calib123456 | 可提交校准、可设禁写区间 |
| inspector | insp123456 | 只看（含钟点配置与痕迹），不许改区间 |

## 钟点闸（班次禁写窗）

- calibrator 在「钟点闸」设每日禁写闭区间（HH:MM–HH:MM，含两端；起晚于止表示跨零点）。
- 服务端按服务器时间对表：落在窗内的提交一律 403 拒收，报文点明禁写窗，并追加一条禁写痕迹；窗外才放行。
- inspector 只许查看区间配置与禁写痕迹，改区间返回 403。

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. calibrator 在「钟点闸」把禁写区间盖住此刻服务器时间，回总览提交 → 拒收并点明禁写窗，痕迹页新增一条；把区间挪开（不含此刻）再提交 → 收下。
5. inspector 打开「钟点闸」能看区间与痕迹，但无编辑表单；直接调 PUT /api/ban-window 返回 403。
