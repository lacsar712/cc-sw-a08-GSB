# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

校准员可在「钟点禁写窗」专页设立每日禁写闭区间（服务端对表，端点也命中，支持跨午夜）；此刻落在窗内的提交一律由服务端拒收（409）并追加禁写痕迹，挪到窗外后才放行。观察账号只能查看钟点配置与痕迹，不能修改区间。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 钟点禁写窗专页：calibrator 设一个盖住当前服务器钟点的闭区间（如当前 15:20 则 15:18–15:22），页面显示「禁写中」。
5. 此时在总览提交，应被拒收并提示落在禁写窗内、请挪到窗外；禁写痕迹新增一条，任务总数不变。
6. 把该区间挪开（如改成 03:10–03:20）后再提交，应被收下并入队出结论，不新增痕迹。
7. inspector 打开专页能看到区间配置与禁写痕迹，但无新增/保存/删除入口；直接调写接口返回 403。
